# Motor inhibition and fine-scale foraging movement in wild gulls

Data and R code supporting the manuscript **“Motor inhibition is associated
with fine-scale foraging movement in wild gulls.”**

## Authors

Kaho Minami, Hibiki Sugiyama, Sota Inoue, Yuichi Mizutani, Yusuke Goto, and
Ken Yoda.

## Repository contents

- `code/`: R Markdown analysis workflow and shared settings
- `rawdata/`: task-performance and GPS input data, plus the breakwater polygon
- `outputs/`: processed tracking data and the fitted HMM object used in the article
- `figure/`: figures generated by the analysis
- `code.Rproj`: RStudio project file
- `software_versions.csv`: R and package versions used for validation

## Reproducing the analysis

Open `code.Rproj` and run the notebooks in `code/` in numerical order. Detailed
execution notes are provided in [`code/README.md`](code/README.md).

The complete HMM fitting notebook is included, but refitting is computationally
intensive. The archived fitted object is included so that the downstream figures
and post-hoc analyses can be reproduced directly.

## External coastline data

The analysis uses the GADM 4.1 Japan level-0 boundary as a coastline polygon.
GADM permits academic use but does not permit redistribution without prior
permission, so its files are not included here. Download the Japan shapefile
from <https://gadm.org/download_country.html> and place these files in
`rawdata/gadm41_JPN_shp/` before running notebooks 03 or 05:

- `gadm41_JPN_0.cpg`
- `gadm41_JPN_0.dbf`
- `gadm41_JPN_0.prj`
- `gadm41_JPN_0.shp`
- `gadm41_JPN_0.shx`
