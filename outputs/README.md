# Derived data and fitted model

These files are generated by the numbered notebooks and are included to support
direct verification of the article. Tabular files are CSV unless noted.

- `GPS_combined.csv`: combined GPS records from all logger types. Coordinates
  are longitude/latitude in WGS84; `time` is Japan Standard Time.
- `filtered.csv`: GPS data after the geographic, quality, and speed/turning-angle
  filters in notebook 02.
- `resampling.csv`: filtered tracks resampled to five-minute bins for the HMM.
  `time_diff_sec` is the interval since the previous retained location.
- `trip_segmentation.csv`: GPS locations belonging to trips defined as movement
  more than 1 km from the nest for more than 1 hour. `Nest_Distance` is metres;
  `Trip_ID` is assigned within individual.
- `03_HMM/03_fit_objects.rds`: pooled and individual four-state HMM objects,
  intermediate HMM data, parameter tables, and individual summaries used by
  notebook 04. This is an R serialized object.
- `Data_HMM_viterbi.csv`: HMM input records with their decoded behavioural state
  (`directed`, `undirected`, `ARS`, or `water`). Projected `x` and `y`
  coordinates are metres in UTM zone 54N (EPSG:32654).
